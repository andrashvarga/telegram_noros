# Noros Telegram (форк Telegram Desktop для Windows)

Что внутри форка:
- **30 аккаунтов** одновременно (вместо 3/6).
- **Иконка = название**: Noros, Valutix, RioPay. Меняется название окна и логотип в левом верхнем углу заголовка.
- **5 тем**: Светлая, Тёмная, Noros, Valutix, RioPay, каждая в двух дизайнах: **Material** и **Liquid Glass**.
- **Анонимное чтение**: сообщения не отмечаются прочитанными у собеседника.
- Автообновление отключено, чтобы форк не заменился официальным клиентом.

Всё включается в Настройки → «Оформление».

## Как получить exe (GitHub Actions)
1. Создайте на GitHub пустой приватный репозиторий и загрузите в него содержимое этой папки (включая `.github`).
2. На https://my.telegram.org/apps получите **api_id** и **api_hash** для своего приложения.
3. В репозитории: Settings → Secrets and variables → Actions → добавьте секреты `TDESKTOP_API_ID` и `TDESKTOP_API_HASH`.
4. Вкладка Actions → «Build Noros portable (Windows x64)» → Run workflow.
5. Первая сборка 3–5 часов (собирается Qt). Если упёрлась в лимит 6 часов, запустите ещё раз: кэш ускорит.
6. Готовый `Noros-portable-x64` скачайте из Artifacts. Внутри `Noros.exe` и папка `tdata`: кладите куда угодно и запускайте.

## Лицензия
Telegram Desktop распространяется под GPLv3. Форк должен оставаться открытым: исходники нужно давать всем, кому вы передаёте exe. Название Telegram и его логотип в форке не используются.

## Если сборка упала
Патчи не компилировались до запуска на GitHub. Пришлите лог ошибки (шаг «Noros build»), я поправлю.

## Пересоздать иконки и темы
`python3 tools/gen_assets.py overlay/Telegram/Resources/noros` (нужны Pillow и numpy). Цвета брендов лежат в словаре `THEMES` в `tools/gen_assets.py`.
